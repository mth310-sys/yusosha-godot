# プレイヤーモード構想 V01

更新日: 2026-09-22
対象: Godot版「ぱち朗」
状態: 構想保存 / 未実装

## 基本コンセプト
既存のホール経営側とは別の「プレイヤーモード」。
一般的なパチスロゲームのように、実機を1Gずつリアル操作すること自体をゲームの中心には置かない。

主人公は「パチスロ好きのフリーター」。
偶然見つけた謎のホールを起点に、金を稼ぎ、ガチャで遊技台を集めていく。

## 世界観
主人公が見つけるのは特殊な「謎のホール」。

ゲーム開始時の店内には、
- 見たことのないスロット台が1台
- 怪しい店員が1人

だけが存在する。

空間自体は、異世界転移に近い特殊な場所を想定。
「主人公は謎のホールを見つけたと思っているが、実はすでに異世界へ転移していた」という可能性も含める。
ただし、これをストーリー上で明かすか、裏設定に留めるか、別の真相に変更するかは未確定。

### 搾取される異世界
この世界の基本原則は「情報・仕事・機会にも対価を要求される」こと。
主人公に対して無償で便宜を図る世界ではなく、何かを得るためには金や特殊コイン等の対価を求められる。

特殊コインは世界の裏側を認識するための鍵ではなく、情報や便宜を買うための対価として扱う。

## ガチャ

### Jガチャ
バイトに関わるガチャ。

ただしバイト先そのものはガチャで直接手に入らない。
主人公が街を徘徊・探索して求人や仕事を発見する必要がある。

バイトを発見しても、必要条件を満たしていなければ働けない。
Jガチャと就業条件の具体的な関係は今後設計する。

### Sガチャ
スロット台が手に入るガチャ。

獲得した台によって、謎のホール内で遊べるスロット台が増えていく。

### Pガチャ
パチンコ台が手に入るガチャ。

獲得した台によって、謎のホール内で遊べるパチンコ台が増えていく。

## 生活と金策
序盤はバイトが基本的な資金源。

街を探索
→ バイト発見
→ 条件を満たす
→ 働く
→ 金を稼ぐ
→ ガチャを回す
→ 新しい遊技台を入手

所持金がなくなれば再びバイトして生活・遊技資金を作る。

一方で「スロットだけで生活する」ことも可能にする。
ただし、その道はかなり険しいものとする。

### 街の怪しい人物
街のどこかに、仕事に関する情報を持つ怪しい人物を配置する。

この人物は善意で仕事を紹介するのではなく、特殊コインを対価として要求する。
特殊コインを渡すことで、
- 仕事の場所を教えてもらう
- バイトを紹介してもらう
- 通常の探索では得にくい仕事情報を得る

といった便宜を受けられる。

怪しい人物の正体・出現場所・紹介できる仕事の種類は未確定。

## 特殊コイン / 情報・便宜の交換
スロットを回して特定条件を満たすことで「特殊コイン」を獲得する。

特殊コインはスキルガチャには使用しない。
この世界で情報や便宜を得るための対価として使用する。

現時点での主な用途は2系統。

1. 謎のホールの怪しい店員に渡し、手に入れた台・遊技台に関する情報と交換する。
2. 街の怪しい人物に渡し、仕事の情報を得る、または仕事を紹介してもらう。

想定する遊技台情報:
- 基本仕様
- 小役・ボーナス確率
- CZ / AT関連
- 設定差
- 設定示唆
- モード / 内部状態
- 天井 / 狙い目
- その他の特殊情報

基本方針として、特殊コインによって台の抽選確率を直接有利にするのではなく、「知ることができる情報」や「得られる機会」を増やす。

特殊コインの使い道が競合することで、
「遊技台の情報を買うか」
「仕事の情報・紹介に使うか」
という資源配分の判断が発生する。


## 遊技機のプレイ方式
遊技機は、実機のように1Gずつレバー・停止ボタンを操作する方式ではなく、選択式で進行する。

基本イメージ:
- プレイヤーが「お金を入れる」を選択
- 台ごとに設定された金額を消費
- 一定または台の仕様に応じたゲーム数が内部で進行
- 進行結果を文章と絵で表示
- プレイヤーは追加投資するか、やめるかを判断
- 当たり等で獲得した通常コインは換金して現金化できる

通常コインと特殊コインは別物とする。
- 通常コイン: 遊技の出玉。換金対象
- 特殊コイン: 情報・仕事紹介等の対価

### 表面は単純、内部は複雑
プレイヤーから見える操作は単純でも、各遊技機の内部には固有の仕組みを持たせる。

候補となる内部要素:
- 設定
- モード
- 内部状態
- CZ
- AT
- 規定ゲーム数
- 天井
- 前兆
- 継続抽選
- 当たり後の状態
- 台固有の特殊条件

そのため、初見では「何か光った」「何かが現れた」程度にしか分からない現象が、情報収集や実戦経験によって意味のある攻略情報へ変化する。

例: 「スロット ゲロッピー」（仮）
- 1,000円投入 → 50G進行 → カエルが3体現れる
- 1,000円投入 → 40G進行 → カエルたちが口をパクパクしている

カエルの数・動作・進行ゲーム数などに内部的な意味を持たせることができる。
具体的な意味は機種設計時に決定する。

遊技中は状態に応じた1枚絵等を表示し、文章だけではなく視覚的な変化も攻略の手掛かりにできる。

### 台ごとのリスクとリターン
遊技料金は全機種一律にせず、台ごとに変更可能とする。
進行ゲーム数の扱いも機種仕様として設計できる。

極端な「危険な理不尽台」も存在可能。
例:
- 1回の投入金額が非常に高い
- 初当たりが極端に重い
- ほぼ天井到達が前提
- 当たりの約9割がほぼ駆け抜け
- 残り約1割のみ非常に大きなリターン

情報を全解放しても必ず勝てるわけではなく、「危険性を理解した上で打つか」を判断する台も作る。

### 攻略と撤去
台の情報を全解放しただけでは即撤去しない。
全情報解放後、さらに台ごとに設定された条件を満たした場合、翌日にその台が撤去される仕組みを想定する。

これにより、完全攻略した1台を永久に利用して稼ぎ続けることを防ぐ。

撤去条件の具体例は未確定だが、
- 一定以上の利益を得た
- 特定の攻略行動を成功させた
- 台固有の条件を達成した
などを候補とする。

撤去後も、その台について一度得た情報・攻略記録は保持する方向とする。

### 撤去台の中古販売
撤去された遊技機は完全消滅とは限らない。

街の怪しい人物が、撤去済みの台を稀に中古遊技機として持ってくる。
再入手には特殊コインではなく、高額な現金を要求される。

特徴:
- 販売されるかどうかは稀
- 販売価格は高額
- 撤去済みの台が対象
- 購入すれば再び遊技可能になる
- 以前に解放した台情報・攻略記録は維持する方向

怪しい人物がどこから撤去台を入手しているのかは未確定とし、世界観上の謎として残せる。

## 現時点の基本ループ
街を探索
→ バイトを発見、または特殊コインを使って仕事情報・紹介を得る
→ 条件を満たして働く
→ 資金を得る
→ 謎のホールへ行く
→ J / S / Pガチャ
→ 遊技台・可能行動が増える
→ スロットを遊技
→ 条件達成で特殊コイン獲得
→ 店員の遊技台情報、または街の怪しい人物の仕事情報・紹介に使用
→ 得た情報・機会を使って次の行動を選ぶ

## オリジナル遊技機設計原則
遊技機は現実のパチスロ規則を忠実に再現する必要はない。

基本思想は「表は単純、中身は変態的」。
プレイヤーが理解しやすい操作・演出を維持しつつ、機種ごとに独自の内部抽選や攻略要素を持たせる。
全機種を共通の設定1〜6・据え置き・設定変更等の仕組みで縛らず、必要な機種だけ固有の内部仕様を持たせる。

## オリジナル遊技機: スロット ゲロッピー

### コンセプト
泥酔したカエル「ゲロッピー」に回復ドリンクを飲ませ、吐かせることを狙う遊技機。

中央にゲロッピー、画面下に回復ドリンク瓶を常時5本表示する。
通常時は1,000円を投入するごとに先頭の瓶を1本飲ませ、1回抽選する。

基本思想は「吐かせたもん勝ち」。
- 少し吐く = RB
- 盛大に吐く = BB
- 虹色演出 = AT
- 吐かずに復活 = ハズレ

RB / BB時は直接的な吐瀉表現をせず、トイレへ駆け込む演出とする。
AT中の吐く演出は虹色・キラキラで抽象化する。

### 通常時の投入
- 1瓶 = 1G = 1回の有料抽選
- 1回の投入額 = 1,000円
- 現金のみ使用可能
- 獲得した通常コインを遊技に再使用することはできない
- RB / BB / AT中は追加投資なし
- RB / BB / AT終了後、通常時へ復帰して次の1,000円投入が必要

### 瓶
瓶は6種類。
- 無地
- 青
- 赤
- 紫
- 金
- 虹

#### 内部瓶色の出現率
| 内部色 | 出現率 |
|---|---:|
| 無地 | 75% |
| 青 | 15% |
| 赤 | 6% |
| 紫 | 2.5% |
| 金 | 1.4% |
| 虹 | 0.1% |

遊技開始時、最初の5本すべての内部瓶色を抽選する。
1本消費して右端へ補充される瓶も、補充時点で内部瓶色を抽選する。
内部では常に5本分の瓶色が決まっている。

#### 表示抽選
内部瓶色と表示色は必ずしも一致しない。
色瓶でも無地として表示されることがあり、瓶が消費されるたびに残っている未公開の色瓶について正体を表示するか抽選する。

通常の表示抽選:
| 内部色 | 表示確率 |
|---|---:|
| 青 | 35% |
| 赤 | 25% |
| 紫 | 18% |
| 金 | 10% |
| 虹 | 3% |

消費直前の表示抽選:
| 内部色 | 表示確率 |
|---|---:|
| 青 | 50% |
| 赤 | 40% |
| 紫 | 30% |
| 金 | 20% |
| 虹 | 10% |

一度正体を表示した瓶は、その内部色の表示で固定する。
最後まで無地表示のまま消費される場合もある。

### 瓶別の通常時抽選
先頭の瓶を飲んだ時、その瓶の内部色に応じてRB / BB / ハズレを抽選する。

| 内部色 | RB | BB | ハズレ | 合計当選 |
|---|---:|---:|---:|---:|
| 無地 | 5% | 2% | 93% | 7% |
| 青 | 8% | 4% | 88% | 12% |
| 赤 | 15% | 10% | 75% | 25% |
| 紫 | 20% | 25% | 55% | 45% |
| 金 | 15% | 60% | 25% | 75% |
| 虹 | 0% | 100% | 0% | 100% |

通常のAT突入抽選:
- RB成立 → 10%でAT
- BB成立 → 50%でAT
- 虹瓶 → BB + AT確定

### RB / BB
- RB = 100枚
- BB = 200枚
- RB / BBはゲーム消化を行わず即払い出し
- RB / BB後、AT当選時は追加投資なしでATへ移行
- AT非当選時はゲロッピーが復活し、通常時へ戻る

### AT
AT突入時点で最低300枚を保証する。
ただしATのコインは突入時には払い出さず、AT終了時に全獲得枚数を一括払い出しする。

ATは5Gを1セットとし、各G独立で30%の「吐く」抽選を行う。

吐いたタイミングによる追加枚数:
| 成功G | 追加枚数 |
|---|---:|
| 1G目 | +100枚 |
| 2G目 | +150枚 |
| 3G目 | +200枚 |
| 4G目 | +300枚 |
| 5G目 | +500枚 |

5G以内に吐いた場合:
- 虹色・キラキラ演出
- 上記枚数をAT獲得予定枚数へ加算
- 新しい5Gセットへ移行

5Gすべてで吐かなかった場合:
- ゲロッピーが完全復活
- AT終了
- 最低保証300枚を含むAT総獲得枚数を一括払い出し

各G30%のため、1セット中に1回以上吐く確率は約83.193%。

#### 大ゲロ
AT中に吐くことに成功した際、その1%で「大ゲロ」へ昇格する。
- 大ゲロ = +3,000枚
- 大ゲロ後もAT継続
- 通常の吐瀉表現ではなく、より派手な虹色・キラキラ演出で処理する

万枚を狙える事故契機として扱う。

### 当選時の瓶リセット
通常時にRB / BBが成立した時点で、残っている瓶列はすべて破棄する。
後方に表示済み・未表示を問わず金や虹などの強い瓶が存在していても持ち越さない。

理由は、当選して吐いた後にゲロッピーが復活し、その通常状態が終了するため。
RB / BB / AT終了後の通常復帰時に、新しい5本すべての内部瓶色を再抽選する。

### 通常コインと換金
遊技で獲得した通常コインの用途は換金のみ。
- 通常コインで遊技することはできない
- 遊技には現金が必要
- ホール内では通常コインを保有できる
- 未換金コインを所持したままホールを出ることはできない

退店するには所持する通常コインを全て換金する必要がある。

換金仕様:
- 1枚あたり5円〜20円
- 換金時価は完全ランダム
- 換金を選択するまでレートは非公開
- プレイヤーが換金を選択した時点でレートを公開
- レート公開後の拒否・キャンセル不可
- 所持通常コインをそのレートですべて換金した後、退店可能

したがって「換金する」という選択自体が退店手続きとなる。

### ゲロッピーの基本進行
1,000円投入
→ 先頭の瓶を1本飲ませる
→ 瓶内部色に応じて抽選
→ ハズレなら次の1,000円投入
→ RB / BBなら即払い出し
→ AT当選なら追加投資なしでAT
→ AT終了時にAT獲得枚数を一括払い出し
→ ゲロッピー復活
→ 瓶5本を全再抽選
→ 通常時へ復帰

プレイヤーから見える操作は単純に保ち、内部では瓶色・表示抽選・RB / BB・AT・大ゲロ等を処理する。
