# Pachirou

Godot版「ぱち郎」の開発領域です。

## 現在の方針

ぱち郎は経営シミュレーション中心の設計から、プレイヤー自身がホールで遊技台を選び、実機モードへ切り替えて遊技するゲームへ方針転換しました。

基本ループ:

1. 3Dホールを閲覧・移動する
2. 遊技台を選択する
3. 選択した台の状態を実機モードへ渡す
4. 実機モードで遊技する
5. 遊技結果を台データへ反映する
6. ホールへ戻る

## 現在残している基盤

- 3Dホール
- スロット島・筐体・椅子
- データカウンター
- 台状態管理
- 筐体演出
- カメラ
- ホールレイアウト

旧キャラクター/NPC系と旧2D試作系は削除済みです。
