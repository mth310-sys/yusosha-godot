# プレイヤーモード構想 V01

更新日: 2026-09-21
対象: Godot版「ぱち朗」
状態: 構想保存 / 未実装

## 基本コンセプト
既存のホール経営側とは別の「プレイヤーモード」。
一般的なパチスロゲームのように、実機を1Gずつリアル操作すること自体をゲームの中心には置かない。

主人公は「パチスロ好きのフリーター」。
偶然見つけた謎のホールを起点に、金を稼ぎ、ガチャで遊技台を集めていく。

## 世界観
主人公が見つけるのは特殊な「謎のホール」。

ゲーム開始時の店内には、
- 見たことのないスロット台が1台
- 怪しい店員が1人

だけが存在する。

空間自体は、異世界転移に近い特殊な場所を想定。
ただし完全な異世界なのか、現実世界の裏側にある異空間なのか等の正体は未確定。

主人公は現実側で生活でき、バイト等で金を稼げる。

## ガチャ

### Jガチャ
バイトに関わるガチャ。

ただしバイト先そのものはガチャで直接手に入らない。
主人公が街を徘徊・探索して求人や仕事を発見する必要がある。

バイトを発見しても、必要条件を満たしていなければ働けない。
Jガチャと就業条件の具体的な関係は今後設計する。

### Sガチャ
スロット台が手に入るガチャ。

獲得した台によって、謎のホール内で遊べるスロット台が増えていく。

### Pガチャ
パチンコ台が手に入るガチャ。

獲得した台によって、謎のホール内で遊べるパチンコ台が増えていく。

## 生活と金策
序盤はバイトが基本的な資金源。

街を探索
→ バイト発見
→ 条件を満たす
→ 働く
→ 金を稼ぐ
→ ガチャを回す
→ 新しい遊技台を入手

所持金がなくなれば再びバイトして生活・遊技資金を作る。

一方で「スロットだけで生活する」ことも可能にする。
ただし、その道はかなり険しいものとする。

## 特殊コイン / 情報交換
スロットを回して特定条件を満たすことで「特殊コイン」を獲得する。

特殊コインはスキルガチャには使用しない。
怪しい店員に渡すことで、手に入れた台・遊技台に関する情報と交換できる。

想定する情報:
- 基本仕様
- 小役・ボーナス確率
- CZ / AT関連
- 設定差
- 設定示唆
- モード / 内部状態
- 天井 / 狙い目
- その他の特殊情報

基本方針として、特殊コインによって台の抽選確率を直接有利にするのではなく、「知ることができる情報」を増やす。

## 現時点の基本ループ
街を探索
→ バイトを発見
→ 条件を満たして働く
→ 資金を得る
→ 謎のホールへ行く
→ J / S / Pガチャ
→ 遊技台・可能行動が増える
→ スロットを遊技
→ 条件達成で特殊コイン獲得
→ 店員と情報交換
→ 得た情報を使って立ち回る

## 未確定事項

- 情報ごとの交換レート
