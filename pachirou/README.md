# Pachirou

Godot版「ぱち郎」の開発領域です。ゼルヴォルトとは同じGodotプロジェクト内で管理しますが、ぱち郎側のシーン・スクリプトは `pachirou/` 配下に分離します。

## 現在のStep

- 10x10の論理グリッド
- 64x32pxのアイソメトリック床
- 仮キャラクター
- 仮スロット筐体（正面・側面・天面）
- 仮椅子
- 床座標と表示座標を分離する `grid_to_world()`

起動確認は `res://pachirou/pachirou.tscn` をGodotで開き、「現在のシーンを実行」で行います。

## 方針

- 内部処理は通常のXYグリッド
- 表示はアイソメトリック
- ゼルヴォルトの既存 `main.tscn` / `main.gd` / autoload は変更しない
- 将来、ぱち郎側からゼルヴォルトを実機遊技シーンとして接続できる構造を目指す
