# プレイヤーモード構想 V01

更新日: 2026-09-21
対象: Godot版「ぱち朗」
状態: 構想保存 / 未実装

## 基本コンセプト
既存のホール経営側とは別の「プレイヤーモード」。
一般的なパチスロゲームのように、実機を1Gずつリアル操作すること自体をゲームの中心には置かない。

主人公は「パチスロ好きのフリーター」。
偶然見つけた謎のホールを起点に、金を稼ぎ、ガチャで遊技台を集めていく。

## 世界観
主人公が見つけるのは特殊な「謎のホール」。

ゲーム開始時の店内には、
- 見たことのないスロット台が1台
- 怪しい店員が1人

だけが存在する。

空間自体は、異世界転移に近い特殊な場所を想定。
「主人公は謎のホールを見つけたと思っているが、実はすでに異世界へ転移していた」という可能性も含める。
ただし、これをストーリー上で明かすか、裏設定に留めるか、別の真相に変更するかは未確定。

### 搾取される異世界
この世界の基本原則は「情報・仕事・機会にも対価を要求される」こと。
主人公に対して無償で便宜を図る世界ではなく、何かを得るためには金や特殊コイン等の対価を求められる。

特殊コインは世界の裏側を認識するための鍵ではなく、情報や便宜を買うための対価として扱う。

## ガチャ

### Jガチャ
バイトに関わるガチャ。

ただしバイト先そのものはガチャで直接手に入らない。
主人公が街を徘徊・探索して求人や仕事を発見する必要がある。

バイトを発見しても、必要条件を満たしていなければ働けない。
Jガチャと就業条件の具体的な関係は今後設計する。

### Sガチャ
スロット台が手に入るガチャ。

獲得した台によって、謎のホール内で遊べるスロット台が増えていく。

### Pガチャ
パチンコ台が手に入るガチャ。

獲得した台によって、謎のホール内で遊べるパチンコ台が増えていく。

## 生活と金策
序盤はバイトが基本的な資金源。

街を探索
→ バイト発見
→ 条件を満たす
→ 働く
→ 金を稼ぐ
→ ガチャを回す
→ 新しい遊技台を入手

所持金がなくなれば再びバイトして生活・遊技資金を作る。

一方で「スロットだけで生活する」ことも可能にする。
ただし、その道はかなり険しいものとする。

### 街の怪しい人物
街のどこかに、仕事に関する情報を持つ怪しい人物を配置する。

この人物は善意で仕事を紹介するのではなく、特殊コインを対価として要求する。
特殊コインを渡すことで、
- 仕事の場所を教えてもらう
- バイトを紹介してもらう
- 通常の探索では得にくい仕事情報を得る

といった便宜を受けられる。

怪しい人物の正体・出現場所・紹介できる仕事の種類は未確定。

## 特殊コイン / 情報・便宜の交換
スロットを回して特定条件を満たすことで「特殊コイン」を獲得する。

特殊コインはスキルガチャには使用しない。
この世界で情報や便宜を得るための対価として使用する。

現時点での主な用途は2系統。

1. 謎のホールの怪しい店員に渡し、手に入れた台・遊技台に関する情報と交換する。
2. 街の怪しい人物に渡し、仕事の情報を得る、または仕事を紹介してもらう。

想定する遊技台情報:
- 基本仕様
- 小役・ボーナス確率
- CZ / AT関連
- 設定差
- 設定示唆
- モード / 内部状態
- 天井 / 狙い目
- その他の特殊情報

基本方針として、特殊コインによって台の抽選確率を直接有利にするのではなく、「知ることができる情報」や「得られる機会」を増やす。

特殊コインの使い道が競合することで、
「遊技台の情報を買うか」
「仕事の情報・紹介に使うか」
という資源配分の判断が発生する。


## 遊技機のプレイ方式
遊技機は、実機のように1Gずつレバー・停止ボタンを操作する方式ではなく、選択式で進行する。

基本イメージ:
- プレイヤーが「お金を入れる」を選択
- 台ごとに設定された金額を消費
- 一定または台の仕様に応じたゲーム数が内部で進行
- 進行結果を文章と絵で表示
- プレイヤーは追加投資するか、やめるかを判断
- 当たり等で獲得した通常コインは換金して現金化できる

通常コインと特殊コインは別物とする。
- 通常コイン: 遊技の出玉。換金対象
- 特殊コイン: 情報・仕事紹介等の対価

### 表面は単純、内部は複雑
プレイヤーから見える操作は単純でも、各遊技機の内部には固有の仕組みを持たせる。

候補となる内部要素:
- 設定
- モード
- 内部状態
- CZ
- AT
- 規定ゲーム数
- 天井
- 前兆
- 継続抽選
- 当たり後の状態
- 台固有の特殊条件

そのため、初見では「何か光った」「何かが現れた」程度にしか分からない現象が、情報収集や実戦経験によって意味のある攻略情報へ変化する。

例: 「スロット ゲロッピー」（仮）
- 1,000円投入 → 50G進行 → カエルが3体現れる
- 1,000円投入 → 40G進行 → カエルたちが口をパクパクしている

カエルの数・動作・進行ゲーム数などに内部的な意味を持たせることができる。
具体的な意味は機種設計時に決定する。

遊技中は状態に応じた1枚絵等を表示し、文章だけではなく視覚的な変化も攻略の手掛かりにできる。

### 台ごとのリスクとリターン
遊技料金は全機種一律にせず、台ごとに変更可能とする。
進行ゲーム数の扱いも機種仕様として設計できる。

極端な「危険な理不尽台」も存在可能。
例:
- 1回の投入金額が非常に高い
- 初当たりが極端に重い
- ほぼ天井到達が前提
- 当たりの約9割がほぼ駆け抜け
- 残り約1割のみ非常に大きなリターン

情報を全解放しても必ず勝てるわけではなく、「危険性を理解した上で打つか」を判断する台も作る。

### 攻略と撤去
台の情報を全解放しただけでは即撤去しない。
全情報解放後、さらに台ごとに設定された条件を満たした場合、翌日にその台が撤去される仕組みを想定する。

これにより、完全攻略した1台を永久に利用して稼ぎ続けることを防ぐ。

撤去条件の具体例は未確定だが、
- 一定以上の利益を得た
- 特定の攻略行動を成功させた
- 台固有の条件を達成した
などを候補とする。

撤去後も、その台について一度得た情報・攻略記録は保持する方向とする。

### 撤去台の中古販売
撤去された遊技機は完全消滅とは限らない。

街の怪しい人物が、撤去済みの台を稀に中古遊技機として持ってくる。
再入手には特殊コインではなく、高額な現金を要求される。

特徴:
- 販売されるかどうかは稀
- 販売価格は高額
- 撤去済みの台が対象
- 購入すれば再び遊技可能になる
- 以前に解放した台情報・攻略記録は維持する方向

怪しい人物がどこから撤去台を入手しているのかは未確定とし、世界観上の謎として残せる。

## 現時点の基本ループ
街を探索
→ バイトを発見、または特殊コインを使って仕事情報・紹介を得る
→ 条件を満たして働く
→ 資金を得る
→ 謎のホールへ行く
→ J / S / Pガチャ
→ 遊技台・可能行動が増える
→ スロットを遊技
→ 条件達成で特殊コイン獲得
→ 店員の遊技台情報、または街の怪しい人物の仕事情報・紹介に使用
→ 得た情報・機会を使って次の行動を選ぶ

## オリジナル遊技機設計原則
遊技機は現実のパチスロ規則を忠実に再現する必要はない。

基本思想は「表は単純、中身は変態的」。
プレイヤーが理解しやすい操作・演出を維持しつつ、機種ごとに独自の内部抽選や攻略要素を持たせる。
全機種を共通の設定1〜6・据え置き・設定変更等の仕組みで縛らず、必要な機種だけ固有の内部仕様を持たせる。

## オリジナル遊技機: スロット ゲロッピー

### コンセプト
二日酔いでグロッキーなカエル「ゲロッピー」に栄養ドリンクを飲ませ、吐かせることを狙う遊技機。

中央にゲロッピー、画面下に栄養ドリンク瓶を常時5本表示する。
1G回すごとに先頭の瓶を1本消費し、残りが左へ移動、右端へ新しい瓶を1本補充する。

### 瓶
瓶は以下の6種類。
- 無地
- 青
- 赤
- 紫
- 金
- 虹

#### 内部瓶色
遊技開始時、最初の5本すべてについて内部瓶色を抽選する。
以降、1本消費して右端へ補充される新しい瓶も、その補充時点で内部瓶色を抽選する。

したがって、内部では常に5本分の瓶色が決まっている。

#### 表示と内部色
内部瓶色と画面上の表示色は必ずしも一致しない。

内部的には色瓶でも、最初は無地瓶として表示される場合がある。
瓶が1本消費されるごとに、残っている「見た目が無地の色瓶」について正体を表示するか抽選できる。

例:
- 内部赤瓶が途中で無地 → 赤へ変化
- 内部金瓶が消化直前まで無地のまま
- 最初から色瓶として表示

これにより、パチンコの保留変化に近い先読み・昇格演出を作る。

具体的な表示率・昇格率は未決定。

### 1瓶ごとの抽選
基本単位は「瓶1本 = 1G = 1回の抽選」。

先頭の瓶をゲロッピーが飲んだとき、その瓶の内部色に応じた確率で結果を抽選する。

無地瓶は通常確率。
青・赤・紫・金・虹は、それぞれ内部瓶色に応じて抽選確率を変動させる。

以下は未決定。
- 各瓶色の出現率
- 各瓶色のRB確率
- 各瓶色のBB確率
- 虹瓶の具体的役割
- 各瓶色の表示率

### 通常時の結果
現時点の基本振り分け案:
- RB: 30% / 100枚
- BB: 20% / 200枚
- ハズレ: 50%

RB成立時は10%でATへ突入。
BB成立時は50%でATへ突入。

この30% / 20% / 50%を瓶色別抽選へどう適用するかは、瓶ごとの具体的確率を設計する段階で最終整理する。

#### 通常時演出
RB・BB時は、直接的な吐瀉表現をせず、ゲロッピーがトイレへ駆け込んで吐く演出にする。
RBとBBでトイレ演出の規模・派手さを変える。

ハズレ時は吐かずにゲロッピーが完全復活する。

### AT
AT突入時の基本報酬は300枚 + α。

ATは5G単位。
5G中は毎ゲーム30%で「吐く」抽選を行う。

5G以内に一度でも吐いた場合:
- 吐瀉物そのものは描かない
- 虹色・キラキラ演出で処理
- AT継続
- 新しい5Gへ移行

5Gすべてで吐かなかった場合:
- ゲロッピーが完全復活
- AT終了

毎G30%抽選の結果、5G以内に1回以上吐く確率は約83.2%。
ただし「継続率83.2%」を直接設定するのではなく、毎ゲーム30%抽選の結果として生じる数値とする。

### 当選時の瓶リセット
通常時に当たりが成立した場合、その時点で残っている5本の瓶はすべて破棄する。

後方に内部的な色瓶が存在していても持ち越さない。
ボーナス終了後に新しい5本すべての内部瓶色を改めて抽選する。

したがって色瓶は「未来の当たり予約」ではなく、その瓶を実際に消費したときに有利な抽選を受けられるものとする。

### ゲロッピーの基本操作
プレイヤー側の基本行動は単純に保つ。

回す
→ 先頭の瓶を1本飲ませる
→ 結果・ゲロッピーの反応を見る
→ 残り5本の表示を見る
→ 続ける

内部では瓶色抽選・表示抽選・瓶色別の当選確率・RB/BB・AT突入・AT中抽選などを処理する。
