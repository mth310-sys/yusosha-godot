# ぱち郎 キャラクター基本仕様 v1
更新日: 2026-09-19
状態: Q1〜Q81確定。Q82（基準キャラ服配色）から再開。

## 基本デザイン
- 約3頭身。男性/女性は別ベース。若者/中年/高齢者。
- 身長はほぼ共通。体格差は幅・手足の太さ・姿勢で表現。
- 体型は標準/細身/太め/小柄寄り等。肩幅・腹部・手足の太さを数値化し、年齢/性別で制約。
- 頭は球体を少し縦につぶした横広形状。頭サイズは僅かな個体差。
- 顔型は丸/標準/細め/幅広など複数。軽い顔面立体感は持つがリアルにしない。
- 首は見た目上ほぼ無し。頭単独では動かさず振り向きは胴体ごと。
- 耳は小さく簡略化。
- 通常顔はかなり小さい黒点目のみ。眉・鼻・口・頬表現なし。口はリアクション時のみ。
- 通常表情は簡素、イベント/強い感情時は強く表現。
- 輪郭線なし。トゥーン調。Godot標準3D影。
- 可愛さは年齢で変える。全体色はゲームらしく鮮やか、衣服は比較的自然色。
- 肌色は現段階では共通1色。

## 身体
- 胴体は樽/楕円型。肩は腕付け根が分かる程度に少し膨らませる。
- 腕/脚は基本円柱。腕は標準長、脚は胴体とほぼ同程度の長さ。
- 脚の太さ/足首の絞りは体型で変える。
- 肘/膝は曲がるが外見上ジョイントを露出させない。
- 腰は内部構造として持ち、服装で見え方を変える。
- 手は標準サイズ、ミトン型＋親指のみ分離。
- 靴は標準ボリューム、別パーツ/交換可能。
- 服は単純スケールでなく体型に合わせシルエット自体を調整。

## 髪
- 前髪/後髪等のモジュール組合せ。
- 造形密度・生え際・頭との境界/ボリュームは髪型ごとに変える。
- 同じ髪型の形状は共通で個体ごとの変形はしない。
- 女性: ショート/ミディアム/ロング。男性: 坊主/短髪/ミディアム＋一部長髪。
- 黒/茶/白髪/グレー＋一部に金/明るい茶等。
- 髪を含む揺れ物なし。

## 衣装・アクセサリー
- 一般客は上下モジュール。スタッフ/イベント/重要キャラは専用衣装可。
- 袖/裾/厚みは服ごとに変える。
- 無地だけでなくボーダー/チェック/簡単なプリント等。特殊キャラは専用柄可。
- 若者/中年/高齢者で衣装プールをかなり分ける。
- Tシャツ/パーカー/パンツ等は男女一部共有。
- 女性はズボン/スカート/ワンピース。ワンピースは一体型衣装可。
- 帽子: キャップ/ハット/ニット帽等。特殊キャラ専用品可。
- メガネ: 丸/四角/細フレーム等＋サングラス。
- ヒゲ: 口/あご/無精ヒゲ等。年齢/性別/属性で出現率変更。
- バッグ: 一部客に肩掛け/ショルダーバッグ程度。
- 年齢差は髪色/髪型/服装＋姿勢/体型で表現。シワ等は基本使わない。
- 一般客は中程度の差、スタッフ/重要人物/特殊客は明確に識別可能。
- 現段階はプリセット生成。ランダム生成は後工程。

## 移動・モーション
- 4方向固定。斜め見下ろし画面では概ね45度方向に見える。
- 歩行テンポは年齢/性格で変える。腕振りは軽く、上下動もごく軽く。
- 待機動作はAI目的/状態で変える。
- 通常動作は少しコミカル、感情リアクションは強く誇張。
- 基本姿勢は年齢/性格で変える。
- 着席: 椅子へ移動→向き合わせ→短く腰を下ろす。離席は対になる立ち上がり。
- 椅子は完全固定。キャラ側がSeatTargetへ合わせる。
- 遊技中は状態で変化。通常は落ち着く、期待時は前傾、当たり時は反応、ハマり時はぐったり等。
- 精密な実機操作は不要。「座って操作している風」でよい。
- 髪/服/アクセサリーの揺れなし。

## ホール内ルール
- 設備/壁は通行不可。
- 椅子は目的がある場合のみ進入でき、通常経路には使わない設備マス。
- 客同士は固定障害物にしない。多少の重なり/すり抜けを許容。
- 同位置で長時間滞留する状態だけ防止。
- すれ違い専用の身体ひねりモーションは作らない。

## Character Base 01
- 若い男性、標準体型、約3頭身。
- 自然な短髪、ダークブラウン。
- Tシャツ＋長ズボン＋スニーカー。
- 服の配色は未決定（Q82）。
- 最初の寸法・造形・モーション基準として制作。

## 実装方針
- 完成済み外部キャラをそのまま使わず、遊創舎/ぱち郎オリジナルとして制作。
- 中程度のポリゴン/ディテール。通常カメラ距離で滑らかに見え、多数客表示にも耐える。
- キャラ本体とゲームロジックを分離し、Visualを交換可能にする。
- 将来状態候補: WALK / SIT / PLAY / CHECK_COUNTER / REACT / LEAVE。
- Map/Grid → Placement/Occupancy → Navigation → Character AI → Seat → Machine と接続。
- 遊技機は着席/操作開始時に作動し、PLAY/REACTと機械状態を連動可能にする。
